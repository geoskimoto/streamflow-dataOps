How It Works
  1. Create New Stations: For each MasterStation not in the Station table, a new Station record is created.
  2. Update Existing: For existing stations, missing metadata (coordinates, catchment area) is filled in from the master record.
  3. No Overwrites: Existing station metadata is preserved; only blank fields are populated.
  4. Agency Detection: Agency is determined from station number pattern (numeric = USGS, alphanumeric = EC).
Note: Large syncs (1000+ stations) may take several minutes. The page will redirect when complete.
