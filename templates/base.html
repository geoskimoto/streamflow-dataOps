Streamflow DataOps Help
Dashboard

View system overview, active configurations, recent logs, and system health metrics. Auto-refreshes every 60 seconds.

Stations

Manage streamflow monitoring stations. You can:

  • Add individual stations manually
  • Import multiple stations via CSV
  • Sync from master station database
  • Export stations to CSV
  • Toggle station active status
Configurations

Create and manage data pull configurations. Each configuration defines:

  • Data Type: Discharge, stage, or both
  • Strategy: Full historical or latest only
  • Schedule: Hourly, daily, weekly, or custom cron
  • Stations: Which stations to pull data from
Execution Logs

View detailed execution history with filters by status, configuration, and date range. Click on any log to see full error details and related runs.

Quick Actions

Access common tasks quickly from the dropdown menu in the navigation bar.

Need More Help?

Check the contextual help on each page or contact your system administrator.
